# Day 03: Login & Register Form UI

A responsive Login and Register Form UI built using HTML and CSS as part of my **20-Day HTML & CSS UI Recreation Challenge**.

## ✨ Features

- Login form with email and password fields
- Registration form with full name, email, password, and confirm password
- Remember me checkbox
- Forgot password link
- Google sign-in button UI
- Font Awesome icons
- Hover and focus effects
- Responsive layout for desktop and mobile screens
- Basic HTML form validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome

## 📚 What I Learned

- Creating structured forms using semantic HTML
- Styling input fields and buttons
- Positioning icons inside input fields
- Using Flexbox for page layout
- Applying hover and focus states
- Making layouts responsive with CSS media queries
- Improving HTML accessibility and form validation

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Click **Register** to navigate to the registration page.

## 📝 Note

This project focuses on the front-end UI. Authentication, Google sign-in, password visibility toggles, and actual password matching require additional JavaScript and/or backend integration.
