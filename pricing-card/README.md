# Day 06 – Pricing Cards UI 💳

A modern and responsive Pricing Cards UI built using **HTML5 and CSS3** as part of my 20-Day HTML & CSS UI Recreation Challenge.

## 📸 Project Overview

This project features three pricing plans — Starter, Professional, and Enterprise — with a clean layout and a highlighted popular plan.

## ✨ Features

- Three pricing plans with different features and prices
- Highlighted “Most Popular” plan
- Modern card-based UI design
- CSS hover effects and smooth transitions
- Responsive layout for desktop, tablet, and mobile
- Consistent spacing, typography, and colors
- Clean and organized HTML and CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- CSS Transitions

## 💰 Pricing Plans

| Plan | Price | Best For |
|---|---|---|
| Starter | $0/month | Personal use |
| Professional | $19/month | Growing teams |
| Enterprise | $49/month | Large organizations |

## 📱 Responsive Design

The layout uses CSS Grid and media queries to adjust the pricing cards for different screen sizes.

## 📚 What I Learned

- Creating responsive card layouts using CSS Grid
- Using Flexbox to align card content and buttons
- Highlighting a featured pricing plan
- Applying hover effects and transitions
- Maintaining consistent spacing across components
